# Phobos Frontend

A lightweight front-end prototype for **Phobos** built with plain HTML, CSS, and JavaScript.

## Run locally

From the repository root:

```bash
python3 -m http.server 8080
```

Then open <http://localhost:8080>.

## Included views

- Sidebar navigation + system status
- Operations dashboard metrics
- Simple interactive chat panel

## Files

- `index.html` — page structure
- `styles.css` — visual styling and responsive layout
- `script.js` — lightweight interactivity for dashboard + chat
